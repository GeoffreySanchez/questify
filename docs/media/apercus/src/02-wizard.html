Bienvenue dans Questify
Questify te guide de quête en quête. Seul QuestieDB est obligatoire ; les autres addons améliorent la navigation. Sans eux, Questify utilise le repère du jeu.
Addons sur cet ordinateur
QuestieDB (obligatoire)(installé)
Données des quêtes : donneurs, objectifs et positions.
ShortestPath Forever(installé)
Calcule le trajet entre les zones : vols, bateaux et portails.
WaypointUI(installé)
Affiche un marqueur 3D et la distance dans le monde.
TomTom(absent)
Affiche une flèche qui pointe vers la destination.
https://www.curseforge.com/wow/addons/tomtom
