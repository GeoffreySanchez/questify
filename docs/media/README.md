# Médias : captures et vidéos / Media: screenshots and videos

Dossier des images et GIF utilisés par le README, le wiki et la page CurseForge.
*Folder for the images and GIFs used by the README, the wiki and the CurseForge page.*

## Formats

| Usage | Format | Taille conseillée |
|---|---|---|
| README et wiki GitHub | PNG (captures), GIF court (animations) | 1280 px de large, GIF < 8 Mo, 10-15 s max |
| Galerie CurseForge | PNG ou JPG | 1920×1080 (16:9), sans interface système autour |
| Vidéos CurseForge | lien YouTube (CurseForge n'héberge pas de vidéo) | 1080p, 30-90 s |

Conseils de prise de vue : interface du jeu à l'échelle par défaut, client en français pour les
images FR (une variante en anglais si possible), pas de nom de personnage ou de guilde réel visible
si tu préfères, `/qf` fermé sauf pour les captures du journal.
